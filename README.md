# Afterlights — NFT Landing Page Concept

An interactive landing page concept for **Afterlights**, an NFT/Web3 project built around a dark, mysterious fantasy world.

The goal was to create an experience that felt more like **entering a world** than simply visiting another NFT website.

## ✦ The Idea

The initial direction was a dark fantasy landing page centered around an ancient door.

Instead of immediately presenting a lot of information, the page was designed to create curiosity and encourage the visitor to **“Enter the Abyss.”**

The concept included:

* Cinematic forest environment
* Ancient door as the main visual focus
* Atmospheric fog and vines
* Subtle environmental movement
* Flying birds with randomized movement
* Character animation
* Interactive “Enter the Abyss” experience
* NFT artwork integrated into the main interaction
* Transition into the deeper story/experience

## ✦ What I Built

I handled the frontend implementation of the concept and focused heavily on the visual experience and animation.

The landing page was built with:

* Layered image composition
* GSAP entrance animations
* Ambient looping animations
* Randomized bird flight paths
* Interactive hover states
* Cinematic page transitions
* Responsive layouts for different screen sizes
* A transition from the landing page into the `/abyss` experience

One of the main ideas was to avoid making the page feel like a collection of static images. Each layer had subtle movement so the environment felt alive.

## ✦ Tech Stack

* **Vue 3**
* **TypeScript**
* **Vite**
* **Tailwind CSS**
* **GSAP**
* **Vue Router**

## ✦ Project Status

This was developed as a **client concept/prototype**.

The project was not taken through the full production phase because the project wasn't ready to continue at the time. I built the landing experience to explore the visual direction and demonstrate what the final product could feel like.

Even though the full project wasn't completed, the prototype gave me an opportunity to experiment with cinematic frontend animation, visual storytelling, and building an experience around a product rather than simply building a conventional website.

## ✦ Why I Built It

I wanted to see how far I could push a relatively simple landing page concept.

The interesting part wasn't just displaying the NFT.
